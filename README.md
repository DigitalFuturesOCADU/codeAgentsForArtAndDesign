# Getting Started with Coding Agents

A plain guide to working with coding agents, for artists and designers. It covers what the pieces are
(harness, model, tools, skills, agents), how a first hour with an agent goes, and what changes by
project type.

**Live site:** https://digitalfuturesocadu.github.io/codeAgentsForArtAndDesign/

One column of text with a sidebar that lists the sections. No build tool and no server side.

| File | What it is |
|---|---|
| `basicsOfAgentsAndTools.md` | The text of the guide. Edit this one. |
| `index.html` | The site. **Generated by `build.py`. Do not edit by hand.** |
| `build.py` | Regenerates `index.html` from the markdown. Needs [pandoc](https://pandoc.org). |
| `assets/guide.css` | Layout and type, copied from the [VS Code setup guide](https://digitalfuturesocadu.github.io/vsCodeSetup/guide/) so the course sites match. The additions for this guide are at the end of the file. |
| `assets/guide.js` | Builds the sidebar, the "In this section" lists and the Back and Next links from the HTML. |
| `.github/workflows/static.yml` | Publishes the repo to GitHub Pages on every push to `main`. |

The text came from `basicsOfAgentsAndTools.md` in the Atelier 1 course repo (commit 334a632, September
2026). This repo now holds the copy the site is built from.

## Updating the text

Edit `basicsOfAgentsAndTools.md`, then:

```bash
python3 build.py
```

Commit both files and push. The site updates about a minute later.

How the markdown maps to the page:

- each `#` heading is a group in the sidebar;
- each `##` heading under it is one sidebar entry, shown as its own page;
- each `###` heading is a sub-entry inside that page;
- a `#` with no `##` headings becomes a single entry;
- text between a `#` and its first `##` is shown as the lead of the first entry.

Links to a section look like `#model`. Links to a sub-section look like `#model--context`. The ids are
the ones pandoc makes from the heading text, so renaming a heading changes its link.
